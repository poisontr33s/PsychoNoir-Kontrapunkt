# 🪦 Digital Necromancy Graveyard

## Formål (Purpose)

Dette er den digitale gravplassen for PsychoNoir-Kontrapunkt prosjektet - en strukturert arkivering av filer og artefakter som ikke lenger tilhører hovedprosjektet, men som bevares for arkeologisk analyse og potensielle oppvækning-ritualer.

*This is the digital graveyard for the PsychoNoir-Kontrapunkt project - a structured archive of files and artifacts that no longer belong in the main project, but are preserved for archaeological analysis and potential resurrection rituals.*

## Struktur (Structure)

### `node_modules_necromancy/`
Graveyard for misplaced Node.js dependencies that were accidentally tracked in git. These dependencies belong in package management, not version control.

**Årsak til gravlegging:** Node modules skal ikke trackes i git - de regenereres fra package.json
**Arkologisk signatur:** `DEPENDENCY_MISMANAGEMENT_CASCADE`

### `deprecated_configs/`
Old configuration files and workflows that have been superseded by the Digital Necromancy Observatory System.

### `experimental_artifacts/`
Failed experiments and prototypes that may contain valuable patterns for future resurrection.

## Psycho-Noir Necromancy Protokoll

When files are moved to the graveyard:

1. **Document the Cause of Death** - Why was this file moved here?
2. **Preserve Archaeological Context** - What was its original purpose?
3. **Tag for Future Resurrection** - Under what conditions might it be useful again?
4. **Update the Necromancy Index** - Maintain searchable metadata

## Den Usynlige Hånd Integration

The graveyard serves as a buffer zone where Den Usynlige Hånd's chaotic influences can be studied and contained without affecting the main codebase. Files here exist in a liminal state - neither fully dead nor alive.
