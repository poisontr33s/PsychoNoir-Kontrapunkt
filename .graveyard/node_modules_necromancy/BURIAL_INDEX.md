## Årsak til Gravlegging (Cause of Burial)
**Archaeological Signature:** `DEPENDENCY_MISMANAGEMENT_CASCADE`

Node.js dependencies (`node_modules/`) were inappropriately tracked in version control. These files should be managed by package managers (npm/yarn) and regenerated from `package.json` during deployment.

## Oppvækning-Protokoll (Resurrection Protocol)

To restore these dependencies in a working environment:


## Lærdommer (Lessons Learned)

1. **Never track generated/downloaded dependencies in version control**
2. **Use .gitignore patterns to prevent accidental inclusion**
3. **Maintain clear separation between source code and runtime environment**
4. **Dependencies should be declarative (package.json) not imperative (checked-in files)**
